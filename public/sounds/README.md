# 音声ファイルの配置

このディレクトリに以下の音声ファイルを配置してください：

## 必要な音声ファイル

1. **thinking-bgm.mp3** - シンキングタイム中のBGM（ループ再生）
   - 推奨: 3分程度のループ可能な音楽
   - 音量: 控えめに設定（後で調整可能）

2. **home-bgm.mp3** または **home-bgm.aac** - TOP画面のBGM（ループ再生）
   - 推奨: 1〜3分程度のループ可能な音楽
   - .mp3 / .aac の両方に対応。未配置の場合は thinking-bgm.mp3 / thinking-bgm.aac を順に試します

## オプションの音声ファイル

以下のファイルを配置すると、より高品質な音声体験が可能です：

3. **thinking-start.mp3** - シンキングタイム開始の音
4. **thinking-end.mp3** - シンキングタイム終了の音

## サンプルで試す

TOP画面のBGMをすぐ試すには、既に **thinking-bgm.mp3** がある場合に `thinking-bgm.mp3` を **home-bgm.mp3** としてコピーして使えます。どちらも無い場合は、任意のMP3を `home-bgm.mp3` の名前で配置してください。

## 使用方法

1. 音声ファイルをこのディレクトリ（`public/sounds/`）に配置
2. ファイル名は上記の通りにしてください
3. ブラウザをリロードすると、音声ファイルが使用されます

## 注意事項

- 音声ファイルが存在しない場合は、Web Audio APIで生成された音が使用されます
- 音声ファイルの形式は MP3、AAC（.aac）、OGG、WAV など、ブラウザがサポートする形式を使用してください
- ファイルサイズに注意してください（大きすぎると読み込みが遅くなります）
